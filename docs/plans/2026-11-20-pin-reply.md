# Pin a Reply Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the user pin one assistant reply and open it in a scrollable overlay at any time until they unpin it.

**Spec:** `docs/specs/2026-11-20-pin-reply-design.md`

**Architecture:** A new `extensions/pin-reply/` folder. `pin-state.ts` holds pure logic (find the last reply text, rebuild the pin from session entries, clamp scrolling) and has `node:test` tests. `viewer.ts` draws the overlay. `index.ts` wires commands, the shortcut, the footer status and storage. The pin is stored with `pi.appendEntry("pin-reply", ...)`, which never reaches the model.

**Tech stack:** TypeScript loaded by Pi, `@earendil-works/pi-coding-agent` and `@earendil-works/pi-tui` (same imports as `extensions/snip-actions`), `node --test` for unit tests.

## Files

## Task 1: Pure pin logic

Interfaces:

```ts
export const PIN_ENTRY_TYPE = "pin-reply";
export type PinData = { text: string; pinnedAt: number };
export type PinEntryData = PinData | { cleared: true };
// Minimal shapes so the module needs no Pi imports.
type BranchEntry =
  | { type: "message"; message: { role: string; content?: unknown } }
  | { type: "custom"; customType: string; data?: unknown }
  | { type: string };

export function lastReplyText(branch: readonly BranchEntry[]): string | undefined;
export function currentPin(branch: readonly BranchEntry[]): PinData | undefined;
export function clampScroll(offset: number, totalLines: number, viewHeight: number): number;
```

- `lastReplyText`: walk backwards; for the first assistant message whose `content` has text parts, return the text parts joined by `"\n"`, trimmed. Skip assistant messages with only thinking or tool calls. Return `undefined` when none is found or the text is empty.
- `currentPin`: the latest `custom` entry with `customType === "pin-reply"` decides. `{ cleared: true }` → `undefined`; `{ text, pinnedAt }` → that pin. Ignore malformed data.
- `clampScroll`: clamp to `[0, max(0, totalLines - viewHeight)]`.

## Task 2: Viewer, commands and shortcut

`viewer.ts`:

```ts
export function openPinViewer(ctx: ExtensionContext, pin: PinData): Promise<void>;
```

- `ctx.ui.custom<void>((tui, theme, keybindings, done) => component, { overlay: true, overlayOptions: { width: "90%", maxHeight: "80%", anchor: "center" } })`.
- Body: `new Markdown(pin.text, 0, 0, getMarkdownTheme())`, rendered at `width - 4` inside a `borderAccent` frame.
- Title: `📌 Pinned · HH:MM` (local time of `pinnedAt`). Footer hint: `↑↓/jk scroll · PgUp/PgDn page · Home/End · Esc/q close`.
- View height = overlay height minus frame/title/hint rows, based on `tui.terminal.rows`. Use `clampScroll` for every move; show `n–m of total` in the hint row when the content overflows.
- Keys via `matchesKey`/`Key` from `@earendil-works/pi-tui`: up/down/k/j by 1, pageUp/pageDown by view height, home/end, escape or `q` → `done()`.

`index.ts`:

- State: `let pin: PinData | undefined`. `refresh(ctx)` sets `pin = currentPin(ctx.sessionManager.getBranch())` and `ctx.ui.setStatus("pin-reply", pin ? theme.fg("accent", "📌 pinned") : undefined)`.
- Call `refresh` on `session_start` and `session_tree`.
- `/pin`: text = `lastReplyText(branch)`; none → `notify("No assistant reply to pin.", "warning")`. Otherwise `pi.appendEntry(PIN_ENTRY_TYPE, { text, pinnedAt: Date.now() })`, refresh, notify `Pinned: <first line, max 60 chars>` (or `Replaced pin: …` when one existed).
- `/pinned` and shortcut `ctrl+alt+p`: no pin → `notify("Nothing is pinned.", "info")`; otherwise `openPinViewer`.
- `/unpin`: no pin → `notify("Nothing is pinned.", "info")`; otherwise append `{ cleared: true }`, refresh, notify `Unpinned.`.
